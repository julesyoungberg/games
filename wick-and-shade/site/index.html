Wick & Shade

A couch co-op about light, shadow, and a narrator who will not stop talking.

Install on the Deck

  1. In Desktop Mode, tap the gold button above. The file lands in Downloads.
  2. In Dolphin, move it to /home/deck/Games (make the folder if it isn't there).
  3. Right-click it → Properties → Permissions → tick Is executable → OK.
  4. Open Steam → Games → Add a Non-Steam Game to My Library… → Browse… → pick the file. Set the file type to All Files if it's hidden.
  5. Return to Gaming Mode and launch it from your library.

Updating? The file name stays the same, so just replace the old file (tick Is executable again) and your Steam shortcut keeps working.

Controllers

On the Who is who? screen, each player presses A on their own controller. The first press is Wick, the second is Shade. Only one controller? Press Y on it to split it in half. In the browser, press a button on each controller once so the page can see it.

Progress saves on the device you play on.
